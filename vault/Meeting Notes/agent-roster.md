## זרימת הפייפליין

```
בריף (vault/Content Briefs/)
        │

┌───────────────────────────┐
│ שלב 1 · קופירייטרית       │  →  output/marketing/  (3 זוויות + הוקים)

│ שלב 2 · קמפיינר           │  →  output/marketing/outbound-kit.md

        │
   ⏸  עצירה לאישור המשתמש

│ שלב 3 · בקרה (המנכ"ל)     │  →  vault/Publishing Log/ + Session Log
```

**כללי הזרימה:**
- ליניארי בלבד — סוכן אחד בכל פעם, בלי הרצה מקבילית.
- כל סוכן מקבל את פלט קודמו כקלט.
- אין דילוג על שלב ואין זליגה אוטומטית בין שלבים.
- אף סוכן אינו שולח דבר לאדם אמיתי. השליחה היא תמיד פעולה ידנית של המשתמש.
