# visual — תמונות השראה של הלקוח

שמים כאן 3–8 תמונות (`.png`, `.jpg`, `.webp`) שמגדירות איך התמונות של הלקוח צריכות להיראות: צילומים שלו, פוסטים קיימים שהוא אוהב, מסמך מיתוג.

ההשראה קובעת **איך** התמונה נראית. **מה** יש בה נקבע בבריף.

כשהתיקייה ריקה, המעצב עובד לפי השורה "הסגנון הוויזואלי" ב-`brand-voice.md` ומציין את זה בדיווח.
