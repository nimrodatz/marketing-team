# Understanding Core Web Vitals and Google search results

**מקור:** [Google Search Central](https://developers.google.com/search/docs/appearance/core-web-vitals)
**תאריך פרסום:** עודכן 2025-12-10
**נאסף:** 2026-09-30

## נקודות מרכזיות
- שלושה מדדים: LCP (טעינת האלמנט הגדול בדף) עד 2.5 שניות, INP (תגובה ללחיצה) מתחת ל-200 מילישניות, CLS (קפיצות בפריסה) מתחת ל-0.1.
- לפי גוגל, המדדים האלה ושאר חוויית הדף "aligns with what our core ranking systems seek to reward". הדף לא מציג אותם כגורם מכריע.
- מודדים ב-Search Console (דוח Core Web Vitals) וב-PageSpeed Insights.

## מה זה אומר ללקוח
פרשנות: מהירות היא לא הדבר הראשון לתקן באתר של ארבעה דפים, אבל תמונות כבדות בנייד פוגעות קודם כל במי שנכנס מהטלפון. בדיקת PageSpeed Insights על `/` ועל `/pergola/` היא קו בסיס. **לא נעשתה בריצה הזאת.**
