# Tutorial: Set up a key event (GA4)

**מקור:** [Google Analytics Help, 12966437](https://support.google.com/analytics/answer/12966437?hl=en)
**תאריך פרסום:** לא צוין
**נאסף:** 2026-09-30

## נקודות מרכזיות
- אירוע מרכזי (key event) מוגדר ב-Admin > Events. אפשר ליצור אירוע חדש ולסמן "Mark as key event", או לסמן אירוע קיים.
- ההגדרה חלה מכמה דקות עד כמה שעות אחרי הסימון, ורק על נתונים חדשים.
- אפשר להפוך אירוע מרכזי להמרה בגוגל אדס. לפי הדף, התכונה "may not be available" לכל נכס.
- מקור משני בחיפוש (lovesdata, analyticsmania) מתאר את סימון הכוכב ב-"Recent events". **לא נקרא במקור ראשוני.**

## מה זה אומר ללקוח
פרשנות: `consent.js` בריפו של האתר כבר שולח `generate_lead` בשליחת טופס ו-`whatsapp_click` בלחיצה על וואטסאפ. אחרי שמדביקים מזהה GA4, צריך לסמן את שני האירועים כאירועים מרכזיים בממשק של GA4.
